# Skill catalog

65 skills. Each entry lists purpose, the business problem, inputs and outputs, my contribution, dependencies, and verification status.

**How to read "Verification":** it restates the evidence each skill gives about itself (dates, live runs, incidents, scripts). Where local session logs add evidence, the entry says so and names the level: discovered (listed), loaded, executed, or tested successfully. The [README](README.md#evidence-levels-discovered-loaded-executed-tested) defines these levels. No skill was re-run while this portfolio was built, and no results were added here that the skill does not state.

**Operational vs. experimental:** an entry whose Verification cites a live run, a client engagement, or an incident was developed through operations. An entry marked design only, prescriptive, template only, parked, doctrine, or "none stated" is experimental: written down, not proven in use.

**How to read "Contribution":** I define the requirements, direct the agents, and check the results against real operations. Most skill text was drafted by Claude Code in my working sessions, from the operations I ran and the decisions, corrections, and rewrites I gave. The private source repo's commits carry Claude co-author trailers. Seventeen skills were generated by OpenAI Codex at my request ([section 6](#6-generated-with-openai-codex-at-my-request)).

Glossary: **JJO** = Jiu Jitsu Outlet, my academy business. **Excelsior** = the member app I am building for it. **MAD** = that app's master architecture document; amendments to it are how scope changes get approved. **Mat Squad** = my consulting work for martial arts businesses and brands. **GHL** = GoHighLevel (HighLevel). COSMOS, RADIANCE, LUSTER, ATLAS, MARBLE and similar names are internal project codenames.
