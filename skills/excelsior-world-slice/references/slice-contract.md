# Slice contract

Record this before implementation:

- Slice name and founder ruling date
- Base branch and base commit
- In-scope visual surfaces
- Explicitly forbidden systems
- Frozen-list amendment governing the work
- Before/after viewport, account, state, and poses
- Mandatory automated gates
- Mandatory physical-device or founder gates
- Evidence directory and PR
- Named debts left untouched
- Exact stop condition

Hard-stop immediately when a required gate fails, Playwright cannot run, the change needs a new amendment, or work reaches a forbidden system. Do not silently reduce the battery, lower a threshold, substitute an emulator, or fold the issue into the slice.
