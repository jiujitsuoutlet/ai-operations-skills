# Rendered-pixel measurement law

- Capture after the scene, labels, bloom, and post-processing are fully painted.
- Match pose, phase, viewport, DPR, browser, account, and feature set between suppression pairs.
- Sample label foreground from painted glyph pixels and background from a proven glyph-free region of the same painted pill.
- Report foreground luminance, background luminance, ratio, pose, and visibility state for tracked labels.
- Report orb maximum, environment maximum, margin, pose, animation phase, floor, and pass/fail.
- Use linear luminance for plane gaps and WCAG relative luminance for text contrast.
- Mark off-screen content as a verification gap, not a contrast failure or pass.
