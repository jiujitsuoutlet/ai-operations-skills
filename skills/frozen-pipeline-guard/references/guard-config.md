# Guard configuration

Build the configuration from the current MAD rather than copying stale defaults.

For each frozen item, record:

- canonical quoted line;
- files and directories;
- exported symbols and factories;
- shader uniforms/includes;
- configuration keys and feature flags;
- invariant tests and evidence artifacts;
- indirect callers that can change the governed result.

Typical tripwire terms include `EffectComposer`, `OutputPass`, tone mapping, exposure, bloom, vignette, pixel ratio, camera laws, orb material factories, emissive crest values, routing, playback, completion, and topology. These are examples only. The dated amendment is authoritative.
