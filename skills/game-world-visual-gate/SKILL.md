# Game World Visual Gate

Build evidence that lets the founder judge the real decision, not an attractive but non-comparable image.

## Establish the comparison

1. Name the question: target direction, defect closure, candidate selection, or implementation acceptance.
2. Freeze viewport, DPR, account state, topology, camera pose, scene features, motion state, and production commit.
3. Use real labels, real topology, real orb count, and the governed member state. Mark illustrative content explicitly.
4. Capture current live, committed reference, and proposed target when the ruling is directional. Capture before/after when the ruling is implementation acceptance.

## Package

- Include HERO-1 plus the nearest pose that reveals the changed material/form.
- Add orbit poses when a 3D form may be camera-dependent.
- Build numbered contact sheets for pose-family or candidate rulings.
- Show crops directly; never hand the founder inaccessible working-tree paths.
- State architecture- and performance-bound gaps separately from what the target closes.

## Self-grade

Grade against the founder's award bar before presentation. Iterate autonomously below 9/10 only when the work remains inside the approved target scope and no production code is authorized. Do not hide legal-but-weaker compromises.
