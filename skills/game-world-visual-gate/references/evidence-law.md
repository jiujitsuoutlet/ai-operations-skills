# Visual evidence law

- Compare identical conditions. If conditions differ, label the comparison invalid.
- Preserve full-frame context and include focused crops; crops alone can hide composition regressions.
- Use lossless PNG for pixel measurements and founder stills.
- Record commit, viewport, DPR, pose, member state, feature flags, browser, and errors.
- Treat a reference image as art direction, not proof that its architecture or performance is feasible.
- Separate measured facts, visual diagnosis, recommendation, and founder ruling.
- Preserve rejected targets and their reasons. Never overwrite the evidence that produced a ruling.
