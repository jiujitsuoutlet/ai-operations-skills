# Campaign Orchestrator

Control sequence and authority. Delegate specialized proof to the named skills; do not compress multiple rulings into one implicit approval.

## Initialize

1. Read repository and Vault operating rules, canonical MAD, relevant amendments, build log, live code/asset map, and the founder's master prompt.
2. Create the campaign ledger from [assets/campaign-ledger.md](assets/campaign-ledger.md).
3. Record branch strategy, phases, global frozen list, measurable floors, protected performance reserve, named debts, merge order, and hard stops.
4. Separate reference aspiration from architectural reality. State which gaps are visual, structural, performance-bound, or amendment-bound.

## Phase sequence

1. **Phase 0 ... Recon and amendment:** zero production code. Verify the real implementation and draft exact campaign laws, budgets, evidence protocol, and headroom funding.
2. **Phase 1 ... Audit:** zero production code, mockups, and art. Walk the real mobile journey and rank defects before taste polish.
3. **Target gates:** create fixed-pose targets or integrate selected assets only to the extent authorized. Self-grade before founder review. Preserve rejected evidence.
4. **Slices:** execute one approved slice at a time using `$excelsior-world-slice`. Each slice owns before/after evidence, full mandatory gates, its own PR, and its own stop point.
5. **Performance recovery:** when a device gate fails, pause visual work and use `$visual-performance-attribution`. Optimization requires a separate scope ruling.
6. **Closeout:** merge only explicitly authorized PRs in ruled order, correct conflicts without rewriting history, log shipped slices/amendments, carry debts, and stop before the next campaign.

Use [references/routing.md](references/routing.md) for specialized workflow routing.

## Hard stops

Stop when any mandatory gate fails, tooling prevents a battery, an artifact is stale or condition-invalid, a frozen system must open, a new MAD amendment is needed, remaining measured headroom crosses the protected reserve, or founder authority ends. Do not waive, average away, or silently fund a failure.

Parallel work is allowed only when explicitly authorized and dependency-safe, such as zero-code recon alongside a device walk. Never parallelize work whose evidence or ruling determines the other path.
